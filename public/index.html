03 / SECURITY FIRST

Trust the code.
Not a mystery download.

The old remote-code bootstrap pattern is excluded. SHADOW loads only explicitly allowlisted plugins. Sensitive values stay in private environment settings, never in the public dashboard or source code.

  • Reviewed plugin allowlist
  • Encrypted MongoDB auth-state storage
  • Private mode as the default
  • No public pairing endpoint
